# מפת אירועים: אפליקציה עצמאית

מקבלת אירוע חדשותי ומחזירה את המניות והמדדים האמריקאיים שהוא משפיע עליהם. זו גרסה עצמאית של הכלי, לא Artifact: שרת Node קטן שמתחבר ישירות לאתרי חדשות, ל-Claude API ולנתוני מחירים.

## הפעלה

```bash
cd event-map
npm install
export ANTHROPIC_API_KEY=sk-ant-...
npm start            # http://127.0.0.1:8787
```

נדרש Node בגרסה 20 ומעלה.

## מה מחובר למה

| שכבה | מקור | הערות |
|---|---|---|
| **פיד חדשות** | פידי RSS של Google News (כותרות מ-Reuters, AP ו-Bloomberg), BBC, Al Jazeera, CNBC, MarketWatch, Guardian, NYT, Times of Israel ו-ynet | הרשימה נמצאת ב-`sources.json` ואפשר להוסיף או להסיר מקורות. הפיד נשמר במטמון ל-5 דקות. |
| **משיכת כתבה** | כל קישור לכתבה | הטקסט נשלף מ-JSON-LD או מ-`<article>`. בכתבה שמאחורי חומת תשלום תתקבל רק הכותרת. |
| **אימות האירוע** | Claude עם `web_search`, מוגבל לאתרי חדשות מרכזיים | פועל רק במצב "אמיתי". רשימת האתרים מוגדרת ב-`VERIFY_DOMAINS`. |
| **ניתוח** | Claude API (`claude-opus-5`) | תיוג one-off או process, בחירת 12 עד 15 מועמדים, ציון חשיפה, תקדים וביקורת. |
| **מחירים** | Yahoo Finance, ו-Stooq כגיבוי | שנה של נרות יומיים, ומהם: סגירה, שינוי חודשי (1M), סטיית תקן של הגאפים, סף 2σ וציון z של הגאפ האחרון. הנתונים לא בזמן אמת. |
| **יומן** | `data/analyses.json` | ניתוחים במצב "אמיתי" או "תרחיש מראש" נשמרים עם מקום לרשום מה קרה בפועל. |

## ההבדל מגרסת ה-Artifact

גרסת ה-Artifact השתמשה בחיבור IBKR של claude.ai כדי לאמת קשרי חברה (מדינה, מוצר, נושא) וכדי למשוך מחירים. החיבור הזה לא זמין מחוץ ל-claude.ai, ולכן:
- **ציון החשיפה** הוא הערכה של Claude עם נימוק (`exposure_basis`), ולא אומת מול נתוני IBKR. הממשק מציין את זה.
- **המחירים** מגיעים מ-Yahoo או מ-Stooq ולא מחשבון IBKR.

## משתני סביבה

| משתנה | ברירת מחדל | הערה |
|---|---|---|
| `ANTHROPIC_API_KEY` | אין | חובה |
| `PORT` / `HOST` | `8787` / `127.0.0.1` | |
| `APP_PASSWORD` | אין | סיסמה ל-Basic auth. **חובה** כשהשרת פתוח לרשת, אחרת כל מי שמגיע אליו יכול להשתמש בקרדיט ה-API שלך. |
| `CLAUDE_MODEL` | `claude-opus-5` | |
| `CLAUDE_EFFORT` | `high` | הערכים `low` ו-`medium` זולים ומהירים יותר |
| `VERIFY_DOMAINS` | רשימה של אתרי חדשות | מופרדים בפסיקים |
| `SOURCES_FILE` | `sources.json` | |
| `DATA_FILE` | `data/analyses.json` | |
